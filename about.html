About Map Mimic

Welcome players! This is Map Mimic, the friendly D&D combat map site that is definitely not a mimic in disguise...


Map Mimic is a free-to-use website meant to be used for online D&D combat (or any in-game exploration with a map). I developed this site as a personal project due to not finding a free website that satisfied my D&D combat map needs. I hope that anybody else who uses this website finds that it suits their needs (and doesn't chomp off any fingers in the process). If it doesn't... feel free to host your own version of the website! You can download the code from MM's Github repo and deploy your own modified version.


The code for Map Mimic is open source and can be found at our Github Repository.
